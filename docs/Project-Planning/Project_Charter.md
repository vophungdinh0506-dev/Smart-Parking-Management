# PROJECT CHARTER

## 1. Thông tin dự án

Tên dự án: Smart Parking Management

## 2. Mục đích dự án

Xây dựng website quản lý xe ra vào và tính phí gửi xe bằng nhận diện biển số.

## 3. Mục tiêu dự án

- Quản lý thông tin xe ra vào.
- Quản lý vị trí đỗ xe.
- Tính phí gửi xe tự động.
- Tra cứu lịch sử gửi xe.
- Thống kê doanh thu.
